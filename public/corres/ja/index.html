Corresのメールの読み方

あなたに何かを求めるメールを、最初に。

ほとんどのメールは、あなたに何も求めていません。Corresは何かを求めているメールを見つけ出し、その理由を伝えます。

要対応

対応が必要なメールから始まる。

あなたに何かを求めるメールが最初に並び、それぞれにここにある理由が添えられます。まだ返信をくれていない相手は、そのひとつ上の行に。ほかのメールは、目を通すときまで「メイン」で待っています。

  • 要対応：あなたに何かを求めるメールだけを、理由とともに
  • 返信待ち：まだ届いていない返信を、あなたが尋ねた内容とともに。遅れているときはお知らせします
  • デイリーまとめ（お好みで）：今日の予定、請求書、配達、返信すべきメールを1枚のカードに。ウィジェットとApple Watchでも

メール

「メイン」には、人からのメールと急ぎのメールを。

その隣には「すべて」「プロモーション」「ソーシャル」「更新」。追加したすべてのアカウントを、Corres独自のルールで振り分けます。「プロモーション」と「更新」は差出人ごとに1行にまとまり、1回のスワイプでその差出人のメールをすべて片付けられます。メールを1通、または差出人のメールをまとめて移動すると、Corresはそこから学習します。学習した内容はすべて設定で確認できます。

  • セキュリティコードや予約の連絡が「更新」に埋もれることはありません
  • 新しい差出人からの最初のメールは、あなたが許可するまで待たせておけます
  • スワイプ、リスト、メール下のツールバーは自由に設定できます

通知

欲しい通知だけを。

Outlookの新着メールは、Corresを閉じていても数秒で通知されます。iCloudも、そのアカウントで「即時通知」をオンにすれば同じです。すべての新着メールか、人からのメールと時間が大切なメールか、対応が必要なメールだけか。アカウントごとに、1つの画面で選べます。

  • 通知からそのままアーカイブ、既読、返信
  • ニュースレターは通知なしで届けられ、VIPからのメールは必ず通知されます
  • デイリーまとめの通知は選んだ時刻に。何もない日は届きません

アカウント

すべてのアカウントを、1つの受信ボックスに。

Gmail、Google Workspace、Outlook、Microsoft 365、iCloud Mail。さらにYahoo、Fastmail、Yahoo! JAPAN、Naver、QQ、163など、ほぼすべてのメールを、メールアドレスとパスワード、またはApp用パスワードで追加できます。Macでは、Proton MailもProton Mail Bridge経由で使えます。アカウントごとに名前、色、通知、署名を設定でき、写真をタップすれば1つのアカウントだけを表示できます。

  • 見慣れた色で：Gmailは赤、Outlookは青、または好きな色に
  • 太字、リンク、ロゴを使える署名。新規メールには正式なものを、返信には短いものを
  • アカウントは一度追加すれば、ほかのデバイスでも使えます

iPhone、iPad、Mac、Apple Watch

どのデバイスでも、同じCorresを。

同じ「要対応」、同じ振り分け、同じアカウントを、どこでも。アカウントは一度追加すれば、iCloudキーチェーンでほかのデバイスにも反映されます。Macでは、「メール」とGmailのキーボードショートカットに対応したネイティブApp。Apple Watchでは、対応が必要なメールと今日のブリーフを、手首と文字盤に。

iPhone Duo

最初の日から、iPhone Duoのために。

開けば、メールリストと読んでいるメールが横に並びます。閉じても、Corresは読んでいた場所を覚えていて、「要対応」は最初のままです。

細部まで

ほかにも、期待どおりの機能をすべて。

Postwrightで動く

Corresは、デバイス上で動く独自のメールエンジンで動作します。アーカイブも削除も、スワイプした瞬間に。電波がなくても同じです。オフラインで送ったメールは、つながった時点で自動的に送信されます。Webやほかのデバイスでの操作も、ここに反映されます。

メールを書く

待っていてくれる下書き、太字、リスト、リンク、ほかのアドレスからの送信、テンプレート、添付忘れのチェック。Apple Intelligence対応のMacでは、「書き直し」で文章を短く、あたたかく、よりフォーマルにしたり、校正したりできます。

あとで送信・送信を取り消す

メールの送信を予約し、だれからも返信がなければリマインダーを受け取り、送ったばかりのメールを取り消せます。iPhone、iPad、Macで。

概要と返信

Apple Intelligenceがあれば、Corresは長いスレッドを要約し、それぞれの概要をメールと照らし合わせて確認します。あなたに何かを尋ねるメールには、あなたらしい文体の返信を用意します。すべてデバイス上で行われ、あなたの確認なしに送信されることはありません。Apple Intelligenceがなくても、「要対応」とその理由、「要約」はそのまま使えます。

検索、または質問

アーカイブ済みのメールも含めて、すべてのアカウントを一度に検索。from:、subject:、before:、in:などのフィルタは入力中に候補として表示され、今いるメールボックスでもすべてのメールでも使えます。または「フライトはいつ？」と尋ねれば、あなた自身のメールから答えが見つかり、その元になったメッセージも表示されます。

新しい差出人

最初のメールの届き方を選べます：全員を確認する、企業だけを確認する、新しい差出人として印を付ける、全員を受け入れる。ブロックするとCorres内で非表示になり、アカウント自体は一切変わりません。

1件ずつ確認

対応が必要なメールを1件ずつ片付けます。返信する、対応済みにする、スヌーズする、アーカイブする。すると次のメールが開きます。「すべて完了」になるまで。

署名付きメール

デジタル署名付きの仕事のメールには署名者が表示されます。「確認済み」が付くのは、Corresがデバイス上で署名と差出人を確認したときだけです。

招待と不在の自動返信

あなたのタイムゾーンでの日時、場所、参加用の通話リンク、空いているかどうかがひと目でわかります。「承諾」「未定」「辞退」はメールの中からそのまま。自動返信も、Corresを離れずにオンにできます。

ルールとミュート

届いたメールをその場で振り分けます。ルールはGmailやOutlookの中でも実行できるので、Corresを閉じていても働きます。会話をミュートすれば、新しい返信が届いても静かなままです。

「要約」を一番上に

請求書の金額、配達日、入金、あるいは相手があなたに求めていることを本人の言葉のまま。メールから読み取って一番上に表示します。Apple Intelligenceは必要ありません。

トラッキングピクセルなし

リモート画像と開封確認のトラッカーは、表示を選ぶまでブロックされます。配信停止はワンタップで。

企業のロゴ

企業がメール用に公開しているロゴを、証明書で裏付けられている場合にだけ表示します。取得するのは私たちのサーバなので、あなたがいつメールを読んだかを企業に知られることはありません。

Siri、ショートカット、ウィジェット

Siriに頼めば、メールを書く、送る、探すことができます。「要対応」とデイリーまとめはウィジェット、コントロールセンター、文字盤に。配達状況はロック画面に表示されます。

29の言語

英語（米国、英国、オーストラリア、カナダ）、日本語、中国語（簡体字、繁体字）、韓国語、ドイツ語、フランス語（フランス、カナダ）、スペイン語、ポルトガル語（ブラジル、ポルトガル）、イタリア語、オランダ語、スウェーデン語、デンマーク語、ノルウェー語、ポーランド語、チェコ語、ルーマニア語、ウクライナ語、トルコ語、アラビア語、ヘブライ語、ベトナム語、インドネシア語、ベンガル語に対応し、アラビア語とヘブライ語は右から左に表示されます。締め切り、請求書、配達は、これらのどの言語で書かれたメールからも読み取られ、週末はお住まいの地域に合わせます。

アクセシビリティ

Appleのアクセシビリティ監査でチェック済み。VoiceOverは直前に起きたことを読み上げ、音声コントロールは人が実際に口にする言葉に応えるので、「削除をタップ」と言えばゴミ箱に移動できます。文字はiPhoneとiPadでは最大サイズまで、Macでは2倍の大きさまで拡大できます。

あなたらしい返信

返信の候補は、あなたがいつも使う挨拶、結び、長さに合わせます。送信済みメールから、デバイス上で学習します。

リマインド

どのメールも、今晩、明日の朝、または期限に合わせてリマインダーに追加できます。そのメールに直接戻れるリンク付きです。

Corresで共有

どのAppからでもページや写真を共有し、共有シートの中でそのままメールを書けます。

Apple Watchで

対応が必要なメール、今日のブリーフ、各メールの冒頭。音声、スクリブル、定型文で返信したり、対応済みにしたりできます。

大きなメールボックスでも速く

数千件の会話があっても、Corresはすぐに最新のメールを表示します。引っ張って更新すれば、数秒で完了します。

プライバシー

あなたのメールは、あなたのデバイスで読まれます。私たちのサーバではなく、AI企業に読まれることも決してありません。

デバイスに保存

メールはメールプロバイダからiPhone、iPad、Macに直接届き、Appleの内蔵暗号化で保護されたままそこにとどまります。Corresのサーバがメールを受け取ることはありません。

デバイス上で振り分け

「要対応」、概要、返信の候補、検索での回答は、すべてデバイス上で動作します。AIサービスに送られることも、その学習に使われることもありません。

売るものはありません

広告なし、解析なし、トラッキングなし、開封確認なし。Corresは、使ってくださる方々の支払いで成り立っています。

3つの小さなサーバが手助けしますが、どれもあなたのメールを読むことはありません。メールボックスに変化があったことだけを知る通知リレー。差出人のWebドメインだけを見るロゴサーバ。そして、iCloudなどパスワードでサインインするアカウントで「即時通知」をオンにした場合に限り、そのパスワードの暗号化されたコピーを保持して新着メールだけを見守るメール監視サーバ。それぞれが何を保持するかは、プライバシーポリシーに正確に記載しています。Google APIから受け取った情報のCorresによる使用および転送は、限定使用の要件（Limited Use）を含め、Google API Services User Data Policyに準拠します。

よくある質問

Corresで使えるメールアカウントは？

GmailとGoogle Workspace、Outlook.com、Hotmail、Live、職場や学校のMicrosoft 365、iCloud Mail、そしてIMAPに対応するほぼすべてのメール：Yahoo、AOL、Fastmail、Zoho、GMX、Yahoo! JAPAN、Naver、QQ、163など。いくつでも追加でき、すべてが1つの受信ボックスにまとまります。iCloudをはじめ多くのサービスでは、メインのパスワードの代わりにApp用パスワードが必要です。作成方法はCorresが順を追って案内します。

ベータ版でGmailアカウントは使えますか？

はい、こちらで登録すれば使えます。GoogleによるCorresの審査が終わるまでは、Googleのテストリストに登録されたアドレスでしかGmailにサインインできず、7日ごとに再サインインを求められます。使いたいGmailアドレスをメールでお知らせください。Outlook、iCloud、そのほかのメールはすぐに使えます。

Corresはサーバ上で私のメールを読みますか？

いいえ。メールはメールプロバイダからiPhone、iPad、Macに直接ダウンロードされ、そこで処理されます。通知リレーが知るのはメールボックスに変化があったことだけで、その中身を知ることはありません。詳しくはプライバシーポリシーをご覧ください。

Apple Intelligenceは必要ですか？

いいえ。「要対応」「返信待ち」、振り分け、「要約」は、対応するすべてのiPhone、iPad、Macで使えます。概要と返信の下書きは、お使いのデバイスがApple Intelligenceに対応していれば、そのデバイス上で利用します。

iPad版、Mac版、Apple Watch版はありますか？

はい。iPadでは3カラム表示。Macでは独自のウインドウ、メニュー、キーボードショートカットを備えたネイティブApp。Apple Watchでは対応が必要なメールを表示し、音声で返信できます。Corres Proは1つでiPhone、iPad、Macに対応し、追加したアカウントはiCloudキーチェーンでどのデバイスにも引き継がれます。

電波がなくても使えますか？

はい。メールはデバイス上にあるので、オフラインでも読めます。アーカイブ、削除、フラグ、送信は、オンラインに戻ったときに自動的に反映されます。

Postwrightとは？

Postwrightは、私たちがCorresのために作ったメールエンジンです。デバイス上で動作し、Gmail、Outlook、iCloudなどのメールサーバとそれぞれに合った方法でやり取りします。だから操作は一瞬で反映され、すべてのアカウントがWeb版と同じ状態に保たれます。Corresがメールを預かる独自のサーバを必要としないのは、このためです。
